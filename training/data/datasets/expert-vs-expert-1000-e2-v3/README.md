## 文件

- `part-001.tar.gz`、`part-002.tar.gz` 保留发布原件。
- `part-001/`、`part-002/` 保留各分片的整盘记录、逐步样本和采集配置。
- `episodes.jsonl` 合并原始 1,000 盘。
- `sources.json` 记录下载地址、发布标签、文件大小和 SHA-256。
- `audit-summary.json` 记录验证范围和结果。
- `deduplicated/episodes.jsonl`、`deduplicated/transitions.jsonl` 保留 362 盘及其原始逐步示范。同走法选择最早完成的一盘，其次按对局 ID 排序。

## 训练使用说明

优先使用去重版比较模型效果，完整重复棋谱需保持在同一数据分区。红蓝胜负分布仍有差异，评估须交换执色并分别报告结果。

发布说明中的 e2-v3 指历史 e2 回退棋局已从该语料排除。这种选择可能影响分布。Expert 是请求参数，实际服务端引擎和版本尚未独立核实。合法性及筛选检查能够支持数据导入，实战棋力仍需通过对局评估。
