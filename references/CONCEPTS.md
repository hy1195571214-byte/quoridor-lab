# 强化学习、策略梯度与 PPO 的通俗解释

## 强化学习与深度学习怎样结合

强化学习研究如何通过行动和反馈改善决策。Quoridor 中，模型根据棋盘选择移动或放墙，获得对局结果，再调整自己的行为。

深度学习使用深层神经网络学习输入与输出之间的关系。用这样的网络读取棋盘、输出行动概率并估计局势价值，就可以构成深度强化学习系统。PPO 规定如何利用经历更新策略参数，网络承担策略和价值的表示。

## 基础术语

| 术语 | 通俗解释 | Quoridor 中的对应内容 |
|---|---|---|
| 环境 | 执行规则并返回反馈的程序 | 棋盘、墙、轮流行动和胜负判定 |
| 状态 | 描述当前游戏情况的信息 | 双方位置、墙布局、剩余墙数和轮到谁 |
| 观察 | 模型实际收到的输入 | 由游戏状态编码得到的棋盘通道和其他信息 |
| 行动 | 模型当前选择执行的操作 | 移动棋子或放墙 |
| 策略 | 根据局面决定如何行动的规则 | 给各种合法行动分配选择概率 |
| 奖励 | 环境返回的即时反馈 | 当前代码中获胜加一、失败减一，未结束通常为零 |
| 回报 | 从当前行动往后累计得到的奖励 | 把后续结果按约定的折扣规则计入当前经历 |
| 价值 | 对后续回报的预期 | 估计从当前局面继续下棋的平均表现 |
| 优势 | 某个行动的表现相对预期好多少 | 利用奖励和价值估计构造的更新信号 |
| 梯度 | 参数改变时训练目标如何变化 | 指导本次网络参数更新的方向 |
| 检查点 | 某个训练时刻保存的模型和状态 | 权重、优化器、进度及恢复所需信息 |

这些定义可结合教材第 3 章及策略梯度相关章节阅读。[教材作者网站](http://incompleteideas.net/book/the-book-2nd.html)

## 策略梯度如何学习

模型根据当前局面给行动分配概率，按照这些概率行动并收集经历。训练根据后续回报，估计怎样改变参数能提高预期的长期表现。

假设在某个局面，模型给向前走、向左走和放墙分配了不同概率。它选择放墙后取得比预期好的结果，更新就会推动它在类似局面下更倾向于放墙。负面的优势信号则推动相反方向的调整。

一盘棋会同时包含有效行动和失误。训练依靠许多局面、选择和后续结果来估计这些关系。价值估计与基线可以减少更新中的随机波动。

反向传播负责计算每个网络参数对训练目标的影响，优化器根据这些影响和学习率更新参数。在训练代码中，这两项工作通常由 `loss.backward()` 和 `optimizer.step()` 执行。REINFORCE 提供了相关更新思想的基础。[REINFORCE 概括](summaries/01_REINFORCE.md)

## PPO 解决什么问题

基础策略梯度已经能够根据回报调整策略。训练时还需要考虑更新幅度，以及同一批经历可以怎样重复利用。

经历由采样时的策略产生。随着模型参数更新，行动倾向会逐渐变化。PPO 保存采样时的行动概率信息，在更新时检查新旧策略的变化，并通过训练目标减少对过度调整的鼓励。

例如，某步放墙的结果比预期好，模型会增加选择它的倾向。当这种倾向已经发生较大变化时，裁剪目标会减少继续沿该方向大幅调整的激励。这样，一批采样可以用于有限轮小批量更新，随后用新策略收集下一批经历。

PPO 中常配合价值网络和优势估计。基础策略梯度也可以采用这些组件，PPO 的代表性设计体现在更新目标和数据使用流程。[PPO 概括](summaries/02_PPO.md)

## 与当前 REINFORCE 示例比较

| 项目 | 当前 REINFORCE 示例 | PPO 候选方案 |
|---|---|---|
| 收集经历 | 完成一盘对局后更新 | 先收集一批对局或片段 |
| 更新依据 | 折扣回报和行动概率 | 优势估计、新旧策略概率及 PPO 目标 |
| 一批经历的使用 | 每盘执行一次参数更新 | 对采样批次执行有限轮小批量更新 |
| 更新幅度 | 当前示例主要通过学习率等设置影响 | 在训练目标中抑制过度的策略变化 |
| 项目状态 | 已有示例代码 | 待实现和检验的方案 |

该表描述当前仓库中的简单 REINFORCE 示例，其他策略梯度实现可以有不同的数据组织和价值估计方式。[现有训练示例](../training/examples/train_policy_gradient.py)

## 为什么需要合法行动屏蔽

Quoridor 的合法行动随局面变化。墙可能已经用完，某个位置可能有墙，某堵墙也可能完全封住通路。规则引擎先生成合法行动集合，模型在这个集合中分配概率和选择行动。

训练中的概率计算和评估中的行动选择，都应使用相应局面的掩码。MaskablePPO 为 PPO 提供行动屏蔽支持，接入时需要核对观察格式、掩码接口和评估流程。[行动屏蔽概括](summaries/03_ACTION_MASKING.md)
