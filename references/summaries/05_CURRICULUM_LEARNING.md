# 强化学习课程学习的通俗概括

原题为 *Curriculum Learning for Reinforcement Learning Domains: A Framework and Survey*，作者 Sanmit Narvekar、Bei Peng、Matteo Leonetti、Jivko Sinapov、Matthew E. Taylor、Peter Stone，发表于 JMLR 2020，共 50 页。[原文 PDF](../papers/05_CURRICULUM_LEARNING_2020.pdf) · [正式出处](https://jmlr.org/papers/volume21/20-212/20-212.pdf)

## 论文研究什么

某些任务很难从零开始学会，原因可能包括奖励稀少、探索困难或任务复杂。课程学习通过安排训练经历的顺序与内容，让已有经验帮助学习后续任务。

这篇文章是一篇综述，整理不同课程学习方法的假设、能力和目标，并给出统一的分类框架。

## 一套课程包含哪些决定

- 选择哪些任务或局面用于训练。
- 决定先练什么、后练什么，以及什么时候回头复习。
- 决定如何把已有知识迁移到下一项任务。
- 决定每个阶段训练多久，什么时候转入下一个阶段。

课程可以由人预先安排，也可以根据学习进展动态调整。任务之间可能改变开局、奖励、难度或对手，也可能在同一任务中重新安排经历。

## 怎样判断课程有帮助

最终在目标任务上比较经过课程训练与直接训练的结果。可以观察最终表现、达到目标水平所需时间，以及总体训练成本。中间任务的训练开销、课程生成开销和迁移成本，也会影响实际收益。

## 本项目怎样使用

可以先观察模型对随机和最短路对手的表现，再逐步加入会放墙的启发式对手、搜索对手和冻结历史模型。难度顺序由实测表现确定，随机行动有时也会制造复杂墙布局。

事先写清阶段对手、抽样比例、训练预算和升级条件。保留一部分旧对手，检查是否遗忘已有能力。固定外部对手用于跟踪进步，自我对弈中的胜率还会受到对手同步变化的影响。

验证课程效果时，可以比较逐步调整对手比例与从一开始固定混合对手的方案，并计入全部前期训练成本。这是根据综述提出的 Quoridor 实验设计。[实验流程](../EXPERIMENT_METHODS.md)
