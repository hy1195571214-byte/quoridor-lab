## 产品定位与核心循环

免费在线抽象策略棋盘游戏，以竞速和阻断路径为核心。双人模式每回合选择走棋或放墙；四人模式争夺中心。

产品围绕同一规则提供电脑练习、实时对战、每日谜题、观战和排行。一个合理的产品循环是：学习规则 → 电脑练习 → 对战 → 回放分析 → 谜题练习 → 再次对战。这个循环是产品分析，不是已取得的留存或收入数据。

## 模式规则

### 双人 Classic

- 9×9 棋盘，红方 e1、蓝方 e9 开局，红方先走。
- 每人 10 道墙，每回合走一步或放一道墙。
- 普通移动上下左右一格；相邻时可跳过对方。
- 对方身后有墙或棋盘边界时，按规则允许从旁侧斜跳。
- 墙长两格，对双方都有效，不能重叠或交叉。
- 每名玩家始终必须保留至少一条到目标边线的路径。
- 两道墙首尾相接的接缝可以穿过另一道墙。
- 到达对面任意边线格获胜；认输和超时也可结束相应模式的棋局。

来源：[规则](https://barricade.gg/rules)。规则边界另经源码与本地实现检查。

### 四人 King of the Hill

官网规则说明使用 11×11 棋盘，四边中点开局，争夺中央；默认每人 7 墙。每回合独立计时，超时有自动移动与连续超时淘汰规则；后期进入不能继续放墙的突然死亡阶段。

这部分为 **DOC**，不能将其描述为我们已实测或已实现。当前 Python 训练环境只实现双人标准模式。

## 界面与信息层次

- 深色主界面，以橙色强调主要操作与当前玩家。
- 桌面端首页采用侧栏；本地对局将棋盘和右侧玩家 / 棋谱面板置于核心区域。
- 棋盘格、墙缝、目标边线、红蓝棋子分别编码。
- 双方卡片显示墙数及当前回合；合法目的地显示轮廓。
- 右侧棋谱按一回合两列排列，墙动作加 h/v 前缀。
- 主棋盘实际用 DOM + CSS Grid 实现，不是由截图推测的 SVG 实现。
- 视频导出有自己的 Canvas 绘制器，浅色导出棋盘与主页面主题分离。

未完成实际手机上的触控、横竖屏和无障碍全面检查。

## 商业与增长设计

官网说明提供免费使用和可选 Premium，条款列举去广告、更多复盘次数和无限谜题等权益；具体价格和权益未在此固定。每日谜题、等级分、排行、观战、分享回放及手机 App 形成持续回访入口。

没有取得独立的流量、活跃用户、留存、收入或付费转化数据，不能据入口完整度推算商业表现。
