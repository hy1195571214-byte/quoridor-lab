# 原站现场核验（2026-11-10）

本次通过 Chrome 直接打开用户指定的 barricade.gg；应用内浏览器不可用。截图由 CUA 直接显示，但其文档未提供截图保存路径，因此本次没有生成独立图片文件。以下是界面观察，不表示服务端算法已知。

## 本地双人 `/local`

桌面宽屏中，黑色背景；没有全站导航侧栏。棋盘和右侧面板并排、同顶同高、整体近似居中。以 1440×824 的显示逻辑像素计，棋盘约 568×568，右栏约 288×568，中间 16；棋盘内格约 48，格间约 12。棋盘深灰圆角底，格为深灰，顶行红褐、底行蓝灰，坐标沿右边与底边。红 e1、蓝 e9，合法目的地为灰白描边。右栏自上而下是大厅、声音、旋转、更多；玩家 2；棋谱；玩家 1；悔棋和认输。当前行动方卡片带强调色边框。

更多菜单有“拖放路障”“切换到浅色棋盘”；启用拖放后，右栏棋谱下方出现可折叠托盘，横向和纵向墙以当前行动方颜色显示。点击 e2 立即记录“1. e2”、切换玩家并启用悔棋。认输第一次变红色“确定？”，两次快速点击后，当前玩家认输；此处玩家 2 认输后显示玩家 1 胜出。结束遮罩覆盖棋盘，右栏仍显示局面；结束卡含“再玩一局”“回到大厅”“分析对局”“下载片段”及注册入口。认输确认超时以前次源码记录的 4 秒为准，本次只验证两次点击有效。

点击结束卡“分析对局”打开新标签 `/analysis?moves=KYJiA`（棋谱仅 e2），棋谱恢复，但不显示原来的认输结果。

## 电脑 `/computer`

配置页没有全站侧栏，顶端左为标志、右为首页，中央单卡选择。难度为简单、中等、困难、进阶、专家；默认简单。执子红方或蓝方，默认红方并提示“你先走”。橙色“开始对局”。专家可直接选择，开始后布局同本地棋盘；右栏标“电脑 · 专家”和“你”，底部只有认输，无悔棋。

Chrome 开发者工具响应式 390×844 下实际观察专家对局：顶部紧凑横排返回、认输、棋谱摘要、更多；对手和自己卡片分别置于棋盘上下，卡片内名称与墙数左右分布；棋盘不显示坐标；墙托盘位于玩家卡下，横向 / 纵向分别为按钮。上述移动截图仅为电脑模式，不能宣称本次已核验移动本地或移动回放。转到本地时 Chrome 显示 ERR_INTERNET_DISCONNECTED。

## 回放与片段

桌面回放 `/analysis?moves=KYJiA` 显示约 232 px 宽全站左侧栏；棋盘及右面板并列。侧栏包括对局、谜题、观战、排行榜、注册/登录、玩法、Premium、语言、设置。右栏列出双方和棋谱，底部有首步、上一步、播放、下一步、末步、速度，以及分析对局、下载、分享、旋转。此前规范中的多步变化及播放细节，本次未重新操作，参见 INTERACTION_SPEC.md 中的既有证据。

下载片段弹窗是全屏变暗遮罩上的深色卡片，标题“下载片段”，右上关闭。中部黑底 9:16 竖版预览中有浅色棋盘；顶部两颗胶囊分别显示红色短墙 + 10 和蓝色短墙 + 10，不显示玩家名。预览下有暂停及进度条。设置三行：速度默认 2×、视角默认玩家 1、声音默认勾选。底部右侧橙色“下载”。本次未下载或检验最终视频。
