## 实测摘要

### 网页专家实战

- 红方由子 agent 执子，蓝方为界面明确标出的“电脑（专家）”。
- 红方先手，23 回合 / 46 个动作自然结束，蓝方走到 i1。
- 终局页面显示“你输了 / 电脑（专家）先抵达终点”。
- 终局红 e1、剩 5 墙，蓝 i1、剩 2 墙。
- 未使用悔棋、认输或状态修改；没有注册、登录或付费。
- 46 个记录动作通过独立规则和编解码核验。
- [对局记录](evidence/expert-game.json) 中的回放链接由完整记谱离线重建，不是已观察到的服务端保存编号；没有再做浏览器整盘回放验证。

### 自动采集

两盘官网专家对局分别执红、执蓝，25、26 个动作后自然获胜。本地对手为最短路基线，不能据此推算对强对手的胜率。

共 51 个动作、26 次真实远程专家决策。HTTP 包装另做了缓存命中检查，没有将其计为额外独立专家采样。数据见 [两盘采集记录](../training/data/live-smoke/episodes.jsonl)。

### 训练链路

两轮模仿训练保存了模型；两盘本地策略梯度示例完成并保存结果。26 条标签不足以证明专家策略已学会，指标见 [验证汇总](../training/data/verification-summary.json)。

## 11 项离线测试

运行 `cd training && .venv/bin/python -m unittest discover -s tests -v`。

1. 209 个动作与规范记谱的双向转换、非法输入。
2. 开局合法行动、非法行动拒绝、旧状态不变。
3. 直跳与身后受阻后的斜跳。
4. 交叉、重叠与首尾接缝。
5. 最后通路和墙数用尽。
6. 46 步真实专家局重放与终局。
7. Gym 观察、动作掩码、先后手和结束边界。
8. 专家请求参数与缓存。
9. 限流 / 非法应手不被替换。
10. 本地 HTTP 行为与非法历史拒绝。
11. 采集中断和恢复，不重复已提交前缀。

Gym 通用检查器会随机取未屏蔽的非法动作，本环境明确拒绝非法动作，所以测试使用合法采样与被动契约检查。不能宣称所有任意 Gym 算法都能不加配置直接训练。
