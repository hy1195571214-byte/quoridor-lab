# 合并 QuoridorCPP 后的训练数据

更新日期：2026-11-23。当前默认语料版本为 `round2-cpp208k-v1`。数据导入与读取验证完成后，用户于当日 19:58 从本地看板手动启动“棋谱预训练 · 第1轮”，使用 Apple GPU；当前进度以看板为准。

## 在本地看板手动启动

打开 <http://127.0.0.1:4173/training>，在页面顶部的“开始新训练”中检查数据数量、训练名称、训练轮数和每批样本数。默认名称为“棋谱预训练 · 第1轮”，模型与设备等选项放在“更多设置”中。默认自动选择可用 GPU；当前本机服务已检测到 Apple GPU。

只有用户点击“开始训练”才调用启动接口。打开页面、刷新页面、切换棋谱或查看配置都不会创建训练任务。旧试运行显示名为“连通性测试”。训练运行时会拦截重复启动。首次完整轮次结束后，保存模型和验证指标。

启动接口先用模拟进程验证，界面检查没有提交真实启动请求；之后的正式运行由用户手动触发并确认继续。大语料的看板棋谱采用分页和按需读取，测试分区不在回放列表中。

## 文件和默认入口

完整数据、独立测试集和原始来源包通过 [GitHub Release](https://github.com/hy1195571214-byte/quoridor-lab/releases/tag/training-data-2026-11-23) 上传，附件地址和 SHA-256 见 [release.json](../training/data/datasets/release.json)。另一台电脑克隆仓库后，在仓库根目录运行 `python training/examples/install_training_data.py`，即可恢复完整的训练、验证、测试分区及本机数据指针。正常训练只需约 69 MB 的完整冻结包，不需要再解压 1.95 GB 上游 ZIP。

Windows 笔记本建议在 WSL2 中准备 Python/PyTorch CUDA 环境，数据尽量放在 WSL 的本地文件系统中。当前服务使用 Unix 文件锁；安装完成后仍需自行打开本地看板并点击“开始训练”。

本机内置盘余量有限，大文件放在外接 HY 硬盘：

```text
/Volumes/HY/QuoridorData/training-datasets/round2-cpp208k-v1/
  episodes.jsonl   # 完整棋谱、来源、胜方和固定分区
  manifest.json   # 每盘哈希、来源、分区、字节偏移及来源校验值
  duplicates.jsonl
  rejected.jsonl
  progress.json
```

项目内 `training/data/datasets/active-dataset.json` 指向本版。训练入口未指定 `--manifest` 时读取它；显式传入 `--manifest` 可以复现实验旧版。HY 未挂载时会明确报错，不会静默回退到旧数据。

本机的 `active-dataset.json`、训练运行目录、日志和样本缓存不写入 Git；下载脚本在目标电脑生成相应指针。当前正在运行的训练保持使用其原始冻结文件和指纹。

在 `training/` 目录使用本机现有环境，以下命令会启动正式训练，仅供后续启动时使用：

```bash
../../barricade-training/.venv/bin/python -m quoridor_lab.supervised \
  --run-dir data/training-runs/cnn32-round2-seed0 \
  --name '棋谱预训练 · 第1轮' \
  --architecture cnn32 --seed 0 --epochs 40 --batch-size 256
```

训练程序对超过 100 万逐步样本的语料自动使用 `stream` 模式。每轮打乱棋局顺序，在默认 8,192 个样本的缓冲区内再打乱逐步样本；每个训练样本每轮访问一次。局面 `[8,9,9]` 和 209 项合法动作掩码按批次生成，避免把全部局面浮点数组一次装入内存。这个顺序是有限缓冲区打乱，不是全部逐步样本的全局均匀打乱。`--shuffle-buffer` 的值纳入恢复训练的指纹，改变它需要新建运行。

测试分区不进入训练或每轮验证。训练恢复仍要求相同冻结清单、随机种子和数据读取配置。旧模型迁移到本版应在新运行目录使用 `--warm-start`，不将新数据冒充原运行的恢复。

数据导入验收已验证真实 CPP 数据的分批读取、目标合法性和 CNN32 前向损失，并通过训练中断恢复一致性测试。这些检查不作为棋力成绩。看板中的“连通性测试”仍属于旧模型；新运行的模型与成绩以完整轮次的检查点和评价记录为准。

复核记录：`training/data/datasets/quoridorcpp-208k/combined-dataset-acceptance.json`。完整走法的初步去重检查保留在同目录的 `pgn-preliminary-audit.json`。
